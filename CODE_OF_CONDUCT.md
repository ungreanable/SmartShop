# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and welcoming, assume good intent, and focus on what is best for the community.
Harassment of any kind is not tolerated.

Report unacceptable behaviour privately to the maintainers through GitHub
(see the repository's Security tab or contact a maintainer listed in the README).
